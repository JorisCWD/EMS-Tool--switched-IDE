# EMS-Tool
This tool is being developd for Croonwolter&dros, telecontrol.
The goal for this project is to provide energy statistics for their costumers. Data will be visually presented in graphs for ease of documentation.

The project was first started in a different file, however the choice was made to rewrite the code base from the ground up using a differen IDE.
At the start of the project, the IDE of choice was Visual Studio Code. However this came with a few complications, so the IDE has been switched to Visual Studio.
